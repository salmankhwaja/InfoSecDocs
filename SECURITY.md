# Security Policy

## Supported versions

Only the latest version on the default branch is supported.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub's **"Report a vulnerability"** button on the
[Security tab](../../security/advisories/new) of this repository, or contact the
maintainer directly via the email on their GitHub profile.

Include steps to reproduce, the affected file, and the impact you expect.
You should get an acknowledgement within 5 working days.
